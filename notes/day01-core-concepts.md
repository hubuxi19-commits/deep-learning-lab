# 1.什么是模型（Model）？

想象你要预测房价。你观察到：房子越大，价格越高。你画了一条直线穿过数据点。这条直线就是一个模型。

在数学上，这条直线是：y = w × x + b

  - x 是输入（面积）           feature
  - y 是输出（预测价格）        model
  - w 和 b 是你还没确定的数字   weight bias

简而言之：模型 = 从输入到输出的一个数学规则。它可以把复杂的现实世界抽象成一个可以计算的函数。

# 2.什么是参数（Parameters）？

上例中 w 和 b 就是参数。参数是模型内部可以调整的数字。

关键点是：
  - 模型结构固定（比如"一条直线"），但参数可以变
  - 不同的参数值 → 不同的直线 → 不同的预测结果
  - 深度学习里，一个模型可能有数百万到数千亿个参数

简而言之：参数 = 模型的"旋钮"，转不同的值得到不同的行为。

# 3.什么是损失（Loss）？

现在你画了一条线预测房价。但你的预测和真实价格差多少？你需要一个数字来衡量这个差距。这个数字就是损失。

比如，你预测 300 万，真实 280 万，差 20 万。对所有样本的差距取平均，就是一个"你的模型有多差"的分数。

简而言之：损失 = 一个数字，告诉你模型当前有多不准。损失越小越好。

# 4.什么是训练（Training）？

训练就是自动调整参数让损失变小的过程。

过程是这样的循环：
  1. 拿一批数据，用当前参数做预测
  2. 计算损失（预测和真实差多少）
  3. 根据损失，微调每个参数（往让损失变小的方向调）
  4. 重复 1-3，直到损失不再下降

简而言之：训练 = 反复"预测→算损失→调参数"的循环。
