## 矩阵乘法与点积 (Day 2)

矩阵乘法 `(m,n) @ (n,p) = (m,p)` 中，中间维 n 必须相等：

- 输出的每个元素 = 左矩阵某一行 × 右矩阵某一列的点积
- 点积要求两个向量长度相同 → 所以 n 必须等于 n
- 例：`(2,3) @ (3,1)` → 左行 [1,2,3] · 右列 [100,200,300] = 1×100+2×200+3×300 =
1400

## 梯度计算 (Day 3)

y = x² + 3x 在 x=2 处的梯度：

- dy/dx = 2x + 3
- x=2 → dy/dx = 2×2 + 3 = 7

梯度值 7 的含义：x 每增加 0.01，y 约增加 0.07。

更新表达式：x = x - lr × 7。梯度为正 → x 减小 → y 减小。

## MSE 与噪声 (Day 4)

 均方误差：MSE = (1/n) × Σ(y_pred - y_true)²

Day 4 结果：loss 最终 = 0.195，不趋近于 0。

原因：数据中注入了 σ=0.5 的高斯噪声，方差 ≈ 0.25，MSE ≈ 0.25×(1 -
模型用掉的部分)。

剩余 loss 是数据本身的噪声，不代表模型没学好。
如果能降到接近 0 反而是问题——说明模型在"背"噪声（过拟合）。



## nn.Linear 的参数 (Day 5)

`nn.Linear(in_features, out_features)` = `y = x @ W^T + b`

- `in_features=1, out_features=1` → 一个输入一个输出
- `model.weight` shape (1,1) → 就是 w
- `model.bias` shape (1,) → 就是 b
- `model.parameters()` 返回这两个，递给 optimizer 管理

### 梯度清零

PyTorch 的 `.backward()` 默认累加梯度。
`zero_grad()` 必须在每次 backward 前调用，否则梯度会从上一轮叠加，参数更新方向被污染。
